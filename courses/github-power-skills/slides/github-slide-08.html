CI & CD: the robots that check and ship

AI fixes one thing, breaks another, and you do not notice until a customer complains.

CI = the checking robotEvery time you push, GitHub tests your code by itself (this is called GitHub Actions). Green tick: all good. Red cross: something broke.

CD = the delivery robotWhen the tests pass on main, it puts the new version online by itself. No uploading by hand.

Why it mattersThe robot finds mistakes before your customers do.
