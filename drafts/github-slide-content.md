## 04 · What is GitHub?
Online storage for your code.

- Save every version
- Undo mistakes
- Put your site online

**Git** = on your laptop · **GitHub** = online

---

## 05 · Why Use It?
- AI broke your app → **Go back**
- Laptop gone → **Code is safe**
- Want it live → **Deploy it**

---

## 06 · 5 Key Words
- **Repo** = project folder
- **Commit** = save
- **Push** = upload
- **Pull** = download
- **Branch** = test copy

---

## 07 · The Flow
**Edit → Commit → Push → Live**

---

## 08 · Just Ask AI
**Setup once:** GitHub account · Install Git · Log in

**Prompts:**
- "Set up Git and commit"
- "Push to a private GitHub repo"
- "Commit and push my changes"

⚠️ Read before you click **Allow**.

---

## 09 · AI Broke It?
- Not saved yet → "Discard my changes"
- Already saved → "Revert my last commit"

💡 Commit before big changes.

---

## 10 · Never Push
- `.env` (API keys)
- `node_modules`
- Customer data

Use `.gitignore`.
⚠️ Leaked a key? Change it now.

---

## 11 · 3 Rules
1. **Commit** before big AI changes
2. **Push** when it works
3. **Never push** `.env`
