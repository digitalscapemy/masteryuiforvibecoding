Branch: a safe place to try something new

Want to add something new to your app, but afraid of breaking the version that is live?

A branch is a separate copy of your code, split off from main. Change anything, and main stays untouched.

The flow: create a branch, let AI
build the feature, test it.

If it works: merge it, which means join it back into main.

If it breaks: delete the branch.
Main is safe.
