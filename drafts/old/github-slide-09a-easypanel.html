Keep the link secret. Anyone who has it can trigger a deploy. Blur it in screen recordings. If it leaks, refresh the token in Easypanel and paste the new link into GitHub.

Shortcut: if the service's source is GitHub, Easypanel's Enable Auto Deploy button sets this up for you. The manual way is to understand the idea.
