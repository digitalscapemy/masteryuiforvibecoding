Webhook: the doorbell that tells your server “there is an update”

How does your server know you just pushed?

A webhook is a link. When something happens on GitHub, GitHub calls that link to tell another system.

Analogy: GitHub rings the doorbell, the server opens the door and deploys.

Warning: the link contains a secret token. Do not share it, and blur it in screen recordings. If it leaks, refresh the token in Easypanel and paste the new link into GitHub.

Shortcut: for a service whose source is GitHub, Easypanel has an Enable Auto Deploy button that sets up this webhook for you.The manual way is for understanding the concept.

In Easypanel, open your app service, go to the Deployments tab, and copy the Deployment Trigger link.

2

On GitHub, open your repo, go to Settings, then Webhooks, and click Add webhook.

3

Paste the link into Payload URL, choose the push event, and save.

4

Push to main. GitHub calls the link, Easypanel builds and deploys, and your app is live.
