Commit: a save point for your code

Yesterday your app worked. Today AI “helped fix it” and everything is broken. How do you go back?

A commit is a snapshot of your code at one moment, with a message about what changed.

Analogy: a save point in a game before the boss fight. Lose, and you reload.

When to commit: every time one thing is done and working, and before asking AI to make a big change.
